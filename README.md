Glimmerdeep 3D: guide Luma the lantern fish through three zones — the Shallow Reef, the Deep Trench, the Abyss — gather 30 pearls before the lamp runs out, and take the Heart of the Deep from the great anglerfish that guards it. Real-time 3D (Three.js r186, vendored locally, no network), a lantern that is a real 3D point light dimming with the light meter, dash, golden pearls, heart pickups, combo multiplier, jellyfish, fog, bubbles and particles, synthesised WebAudio sounds, keyboard and mouse play, all offline from static files.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Enter or click to dive, Arrow keys or WASD (or hold the mouse) to swim, Shift to dash, P to pause, M to mute, R to dive again.
