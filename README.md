Glimmerdeep: guide Luma the lantern fish through a dark reef, gather 30 pearls before the lamp runs out, and dodge the anglerfish. Canvas art, synthesised WebAudio sounds, keyboard and mouse play, all offline from static files.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Enter or click to dive, Arrow keys or WASD (or hold the mouse) to swim, P to pause, M to mute, R to dive again.
